## 一、第三类买点（三买）确认与区间划分

### 核心几何条件

次级别走势向上突破中枢 A=[ZD, ZG] 创出高点 H_{leave} 后，后续次级别 **回踩段最低点 L_{pullback} > ZG**（绝不触碰或跌破中枢高点 ZG）。

### 确认区间划分

| 区间 | 公式 | 含义 |
|------|------|------|
| 黄金买入区间 | [ZG + 0.01, ZG + (H_{leave} - ZG) × 0.382] | 回踩确认后的最优建仓区域 |
| 硬性失效边界 | ZG | 若跌破 ZG，宣告三买破坏，转化为中枢震荡或扩展 |
| 安全缓冲垫 | Cushion = L_{pullback} - ZG > 0 | 回踩低点与中枢高点的安全距离 |

### 次级别完备性

回踩段内部需满足"走势必完美"——至少包含 **3 笔结构**或出现 **次级别底背驰/能量衰竭共振**。

### 状态判定

| 条件 | 状态 | 含义 |
|------|------|------|
| L_{pullback} > ZG | CONFIRMED_THIRD_BUY | 三买确认成功 |
| ZG ≥ L_{pullback} ≥ ZD | REJECTED_CENTER_EXPANSION | 进入中枢区间，转化为中枢震荡/扩展 |
| L_{pullback} < ZD | REJECTED_CENTER_REENTRY | 重回中枢内部，三买破坏 |

## 二、第三类卖点（三卖）确认与区间划分

### 核心几何条件

次级别走势向下跌破中枢 A=[ZD, ZG] 创出低点 L_{leave} 后，后续次级别 **反弹段最高点 H_{rebound} < ZD**（绝不触碰或突破中枢低点 ZD）。

### 确认区间划分

| 区间 | 公式 | 含义 |
|------|------|------|
| 黄金卖出区间 | [ZD - (ZD - L_{leave}) × 0.382, ZD - 0.01] | 反弹确认后的最优卖出区域 |
| 硬性失效边界 | ZD | 若突破 ZD，宣告三卖破坏，重回中枢内部 |
| 安全缓冲垫 | Cushion = ZD - H_{rebound} > 0 | 反弹高点与中枢低点的安全距离 |

### 次级别完备性

反弹段内部需满足"走势必完美"——至少包含 **3 笔结构**或出现 **次级别顶背驰共振**。

### 状态判定

| 条件 | 状态 | 含义 |
|------|------|------|
| H_{rebound} < ZD | CONFIRMED_THIRD_SELL | 三卖确认成功 |
| ZD ≥ H_{rebound} ≥ ZG | REJECTED_CENTER_EXPANSION | 进入中枢区间，转化为中枢震荡/扩展 |
| H_{rebound} > ZG | REJECTED_CENTER_REENTRY | 重回中枢内部，三卖破坏 |

## 三、函数调用接口

```python
from tradingagents.daily_report.chanlun_strategy import evaluate_third_buy_sell

result = evaluate_third_buy_sell(
    center={"zg": 10.0, "zd": 9.0},
    leave_segment=pullback_df,  # pd.DataFrame 需含 high/low 列
    pullback_segment=pullback_df,
    signal_type="third_buy",    # 或 "third_sell"
    sub_level_resonance=True    # 次级别是否共振确认
)
```

### 返回值结构

```python
{
    "is_confirmed": True,        # 是否确认
    "status": "CONFIRMED_THIRD_BUY",  # 状态码
    "invalid_boundary": 10.0,    # 失效边界
    "optimal_buy_min": 10.01,    # 黄金买入区间下限
    "optimal_buy_max": 10.76,    # 黄金买入区间上限
    "cushion": 0.3,              # 安全缓冲垫绝对值
    "cushion_ratio": 0.03,       # 安全缓冲垫相对比率
    "reason": "三买确认成功: ..."  # 判定原因文本
}
```

## 四、与现有缠论系统的关系

- 本规则补充了 `beichi_analyzer.py` 中 V3/V4 三买检测的**严格几何边界**

- 黄金区间采用斐波那契 0.382 分位，兼顾确认性与价格优势
