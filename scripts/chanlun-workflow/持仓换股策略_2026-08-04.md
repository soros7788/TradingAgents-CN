# 持仓换股策略 — 去弱留强，集中到一只完成完整周期

> 策略版本: v1.0 | 生成日期: 2026-08-04 | 适用账户: 婴儿账户(<5万)

---

## 一、核心理念

**婴儿账户资金有限（<5万），持仓不宜分散。** 多只持仓会稀释每只股票的资金效率，增加管理成本，且无法在单只股票上完成完整的"一买建仓→二买加仓→三买确认"周期。

**最终目标**：从多只持仓中逐步去弱留强，最终集中到一只最具潜力的股票，完成完整的买卖周期。

---

## 二、完整周期定义

```
一买建仓 → 二买加仓 → 等待三买确认 → 趋势延续/止盈离场
```

| 阶段 | 操作 | 条件 | 仓位变化 |
|------|------|------|---------|
| 一买建仓 | 首次买入 | DL_P≥0.9, 日线级别背驰一买确认 | 建立初始仓位(10-15%) |
| 二买加仓 | 加仓 | 一买结构有效+回踩不破+DL_P维持高位 | 加仓至20-25% |
| 三买确认 | 持有观望 | 突破中枢+回踩确认不破 | 维持仓位, 不加不减 |
| 趋势延续 | 持有/止盈 | 趋势延续中, 分批止盈 | 逐步减仓兑现 |

---

## 三、持仓筛选标准（去弱留强）

### 3.1 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| DL_P | 40% | 背离概率, 越高越好, 优先≥0.95 |
| 仓位规模 | 15% | 单股占比10-20%为最佳, 太小(<5%)和太大(>25%)均扣分 |
| 周期完整性 | 20% | 一买已确认+二买待确认为最优, 一买未确认扣分 |
| 止损空间 | 10% | 距一买低点≥8%为安全, <5%为高风险 |
| 浮盈状态 | 10% | 浮盈为正加分, 浮亏扣分 |
| 信号一致性 | 5% | 多级别信号对齐加分 |

### 3.2 评分公式

```
综合得分 = DL_P×0.40 + 仓位评分×0.15 + 周期评分×0.20 + 止损评分×0.10 + 浮盈评分×0.10 + 一致性评分×0.05
```

### 3.3 淘汰规则

- **强制淘汰**: DL_P<0.5 或 破一买低点或 不在候选池
- **优先淘汰**: 边缘池标的、浮亏标的、仓位占比<5%的微仓
- **观察保留**: 核心池标的、浮盈标的、仓位适中

## 四、集中策略执行流程

### 阶段一：快速清仓（P0）

清仓所有不符合持仓条件的标的：

| 条件 | 操作 | 时限 |
|------|------|------|
| DL_P<0.5 | 市价清仓 | 开盘立即执行 |
| 破一买低点 | 市价清仓 | 开盘立即执行 |
| 不在候选池 | 市价清仓 | 1个交易日内 |
| 边缘池且浮亏 | 市价清仓 | 1个交易日内 |

### 阶段二：逐步减仓（P1-P2）

对保留的持仓进行进一步筛选：

| 条件 | 操作 | 时限 |
|------|------|------|
| DL_P<0.85（边缘池） | 若浮盈>5%考虑止盈 | 观察1-3个交易日 |
| 仓位占比<5% | 考虑合并到主力标的 | 观察1-3个交易日 |
| 多只核心池标的 | 保留评分最高的1-2只 | 持续评估 |

### 阶段三：集中持有（P3）

最终保留1只主力标的，完成完整周期：

| 操作 | 说明 |
|------|------|
| 一买建仓 | ✅ 已完成 |
| 二买加仓 | 等待回踩不破+量能确认, 加仓至20-25% |
| 三买确认 | 等待突破中枢+回踩确认 |
| 趋势延续 | 分批止盈, 逐步兑现 |

## 六、风险管理

### 6.1 集中持仓的风险

| 风险 | 应对措施 |
|------|---------|
| 单只股票黑天鹅 | 严格止损(破一买低点立即清仓) |
| 错过其他机会 | 集中持仓本身就是放弃其他机会, 追求确定性而非数量 |
| 二买失败 | 跌破一买低点止损, 不侥幸不补仓 |

### 6.2 纪律要求

1. **不提前加仓**: 二买必须在回踩不破+量能确认后执行
2. **不追高**: 三买确认前不加仓, 等待结构完成
3. **严格止损**: 破一买低点无条件清仓
4. **分批止盈**: 趋势延续中分批兑现, 不贪婪最后一分钱
